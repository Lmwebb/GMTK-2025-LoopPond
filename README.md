# 🦆 LoopPond: The Ascent

> Explore the cave as a duck in search of freedom. Collect pickups to extend each loop, and dodge enemy projectiles, scary spikes and aggressive slimes as you ascend.

A 2D platformer built with **Godot** in **GDScript**.

---

## 🎮 How to Play

The game runs right in your web browser. No download needed.

**https://lmwebb.itch.io/looppond-web**
